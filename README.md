# 🛒 AtliQ Mart Sales Performance Dashboard

## 📌 Project Overview
This project focuses on analyzing AtliQ Mart sales performance using Excel and Power BI dashboards.  
The dashboard provides insights into product sales, promotional performance, quantity sold, and revenue trends.

The project was created to improve data analysis and dashboarding skills using real business scenarios.

---

# 📊 Key KPIs

- Total Revenue: 247.98M
- Average Sale: 165.32K
- Total Events: 1500
- Diwali Sale Revenue: 160.29M

---

# 📈 Dashboard Insights

The dashboard includes:

- Top 5 Products by Sales
- Bottom 5 Products by Sales
- Quantity Sold by State
- Quantity Sold by Promotion Type
- Festival/Event Sales Analysis
- KPI Tracking and Performance Monitoring
